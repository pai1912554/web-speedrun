# Web Speedrun

เว็บฝึกสร้างเว็บจากศูนย์ สำหรับแข่งเขียนเว็บคนเดียวภายใน 3 ชั่วโมง
HTML + CSS + JavaScript ล้วน ไม่ต้องติดตั้งอะไร เปิดไฟล์ก็รัน

**เปิดใช้งาน: https://pai1912554.github.io/web-speedrun/**

---

## ห้องปฏิบัติการ (studio/) — เริ่มที่นี่

ซ้ายคือใบสั่งงานทีละขั้น ขวาคือกระดานที่แสดงผลทันที
มีปุ่ม **เส้นบอกระยะ** ที่ทับค่าจริงลงบนแบบ — ช่องไฟกี่พิกเซล ตัวอักษรขนาดเท่าไหร่

| ห้อง | เวลา | ฝึกอะไร |
|---|---|---|
| [ฝึกตาออกแบบ](studio/design-eye.html) | 20 น. | 8 คู่เปรียบเทียบ เนื้อหาเดียวกัน ต่างกันจุดเดียว |
| [LAB 01 หัวเว็บ](studio/lab-01-hero.html) | 25 น. | ลำดับสายตา สเกลระยะห่าง สเกลตัวอักษร จุดเน้นเดียว |
| [LAB 02 ตารางการ์ด](studio/lab-02-cards.html) | 25 น. | Grid ที่ responsive เอง กายวิภาคการ์ด สัดส่วนรูป |
| [LAB 03 แถบเมนู](studio/lab-03-nav.html) | 20 น. | Flexbox การจัดแนว sticky เมนูมือถือ |
| [LAB 04 ฟอร์ม](studio/lab-04-form.html) | 22 น. | ป้ายกำกับ สถานะโฟกัส ข้อความผิดพลาดที่บอกวิธีแก้ |
| [LAB 05 แดชบอร์ด](studio/lab-05-dashboard.html) | 28 น. | ออกแบบข้อมูล สีเชิงความหมาย กราฟ CSS ล้วน |

## ส่วนอื่น

- **`lessons/`** — บทเรียน 6 บท เปิดเมื่อสงสัย รวมถึงแผนรบ 3 ชั่วโมง และตารางแปลโจทย์เป็นเทคนิค
- **`templates/`** — 8 หน้าเว็บพร้อมใช้ ไฟล์เดียวจบทุกอัน (landing, dashboard, CRUD, form, login, gallery, blog, portfolio)
- **`snippets/`** — 16 ชิ้นส่วนพร้อมปุ่มคัดลอก (modal, tab, toast, dark mode, chart, validation ฯลฯ)

```
ระยะห่าง   4 · 8 · 16 · 24 · 40 · 64        ห้ามใช้ค่านอกชุด
ตัวอักษร   48/800 · 24/700 · 16/400 · 13/500
สี         พื้น 1 · ตัวอักษรเข้ม+จาง · เส้น 1 · สีเน้น 1 (ใช้ 2-3 ที่เท่านั้น)
```

## เปิดในเครื่อง

```bash
git clone https://github.com/pai1912554/web-speedrun.git
```

เปิดโฟลเดอร์ใน VS Code แล้วคลิกขวาที่ `index.html` > Open with Live Server
(ต้องเปิดผ่าน Live Server ไม่ใช่ `file://` เพราะตัวอย่าง `fetch` ต้องใช้เซิร์ฟเวอร์)
