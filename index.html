กฎ 5 ข้อ ท่องให้ขึ้นใจ

  1. ทำให้ "เห็นภาพ" ก่อนทำให้ "ทำงาน" — กรรมการเห็นหน้าจอก่อนเห็นโค้ด. หน้าเปล่าที่สวย > ระบบเทพที่รันไม่ขึ้น.
  2. ห้ามติดตั้งอะไรตอนแข่ง — ไม่ npm ไม่ framework. HTML+CSS+JS ล้วน เปิดไฟล์ก็รัน.
  3. ข้อมูลปลอมก่อนเสมอ — เขียน array ของ object ไว้บนสุดของไฟล์ แล้ว render. ค่อยต่อ API ทีหลังถ้ามีเวลา.
  4. ทำงานได้ 1 อย่างสมบูรณ์ ดีกว่า 5 อย่างครึ่งๆ — กรรมการกดปุ่มแล้วพัง = ตายทันที.
  5. Save + เปิดดูในเบราว์เซอร์ทุก 10 นาที — อย่าเขียนยาว 40 บรรทัดแล้วค่อยดู. พังแล้วหาไม่เจอ.
