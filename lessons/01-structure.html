LESSON 01

โครงสร้าง HTML & หลักออกแบบ

เป้าหมายบทนี้: มองหน้าเว็บไหนก็ได้แล้ว "แตกเป็นกล่อง" ได้ในหัวภายใน 30 วินาที.

1. ความจริงข้อเดียวที่ต้องเข้าใจ

HTML ไม่ใช่ภาษาโปรแกรม. มันคือการใส่กล่องซ้อนกล่อง. ทุกแท็กคือกล่อง 1 ใบ. จบ.

เว็บสวยๆ ทุกเว็บในโลก = กล่องที่จัดเรียงดี + ระยะห่างสม่ำเสมอ + สีไม่มั่ว. ไม่ได้ยากกว่านั้น.

2. โครงกระดูกที่ใช้ได้กับทุกโจทย์

จำโครงนี้อันเดียว ใช้ได้ 90% ของงานแข่ง:

<!doctype html>
<html lang="th">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width,initial-scale=1">
  <title>ชื่อเว็บ</title>
  <style> /* CSS ทั้งหมดอยู่ตรงนี้ */ </style>
</head>
<body>
  <header>  โลโก้ + เมนู        </header>
  <main>
     <section> Hero: พาดหัวใหญ่ + ปุ่ม </section>
     <section> เนื้อหา/การ์ด/ตาราง      </section>
     <section> ฟอร์ม/ติดต่อ            </section>
  </main>
  <footer>  ลิขสิทธิ์ + ลิงก์      </footer>
  <script> /* JS ทั้งหมดอยู่ตรงนี้ */ </script>
</body></html>
เทคนิคแข่ง: ไฟล์เดียว — CSS ใน <style>, JS ใน <script>. ไม่ต้องสลับไฟล์ ไม่ต้องกังวล path พัง. ส่งงานง่าย. แยกไฟล์ทีหลังถ้าโจทย์บังคับ.

3. แท็กที่ต้องรู้จริง (มีแค่นี้)

แท็กใช้ทำอะไรจำสั้นๆ
divกล่องเปล่า ไม่มีความหมายใช้ตอนอยากจัด layout
section header main footer navกล่องเปล่าที่มีความหมายเหมือน div แต่กรรมการชอบ (semantic)
h1–h6หัวข้อh1 มีอันเดียวต่อหน้า
pย่อหน้าข้อความ
a hrefลิงก์href="#id" = เลื่อนในหน้า
img src altรูปลืม alt = เสียคะแนน accessibility
ul > liรายการเมนู, list ทุกอย่าง
buttonปุ่มกดทำอะไรอย่าใช้ div ทำปุ่ม
form input label select textareaรับข้อมูลดูบท 03
table tr th tdตารางข้อมูลใช้กับข้อมูลจริงเท่านั้น ไม่ใช่ layout
spanกล่องเล็กในบรรทัดไว้ทำสีคำเดียว

แค่นี้ครับ. 12 อย่าง. คนที่เขียนเว็บมา 5 ปีก็ใช้ประมาณนี้.

4. class คือหัวใจ — id แทบไม่ใช้

<div class="card">...</div>   →  CSS เขียน  .card { }
<div id="total">...</div>     →  JS เขียน   document.getElementById('total')

กฎง่าย: class = ไว้แต่งสี · id = ไว้ให้ JS จับ. ตั้งชื่อ class เป็นภาษาอังกฤษสื่อความหมาย เช่น card, btn, nav, hero, grid. อย่าตั้งว่า red-big-text — วันหลังเปลี่ยนสีแล้วชื่อโกหก.

5. หลักออกแบบ 5 ข้อ (อันนี้แหละที่ทำให้ชนะ)

5.1 ระยะห่าง สำคัญกว่าสี

งานมือใหม่ดู "ไม่โปร" เพราะระยะห่างมั่ว. แก้ด้วยการใช้ระยะแค่ 6 ค่า ห้ามใช้ค่าอื่น:

4px · 8px · 16px · 24px · 40px · 64px

อยากห่าง? เลือกจาก 6 ค่านี้เท่านั้น. ห้าม 13px ห้าม 27px. แค่นี้งานจะดูเป็นระบบทันที.

5.2 สี ใช้ 3 กลุ่มพอ

พื้นหลัง 1 สี  +  ตัวอักษร 2 สี (เข้ม/จาง)  +  สีแบรนด์ 1 สี
ที่เหลือ: เขียว=สำเร็จ เหลือง=เตือน แดง=ผิดพลาด

สีแบรนด์ใช้เฉพาะของสำคัญ: ปุ่มหลัก, ลิงก์, ตัวเลขเด่น. ถ้าทุกอย่างเด่น = ไม่มีอะไรเด่น.

5.3 ขนาดตัวอักษร ใช้ 4 ระดับ

32–48px หัวเรื่องใหญ่ (h1)
20–24px หัวข้อ (h2)
16px    เนื้อหา
13–14px ข้อความรอง/ป้ายกำกับ

และตั้ง line-height:1.6 ให้ข้อความ — มือใหม่ลืมข้อนี้ งานเลยดูอึดอัด.

5.4 ความกว้างต้องมีขอบเขต

ข้อความยาวเต็มจอ 27 นิ้ว = อ่านไม่ไหว. ครอบด้วย wrapper เสมอ:

.wrap{ width: min(1080px, 100% - 32px); margin-inline: auto; }

บรรทัดเดียวนี้จัดกลาง + กันชนขอบจอมือถือ + จำกัดความกว้าง ครบในตัว. ท่องให้ได้.

5.5 ลำดับสายตา (visual hierarchy)

คนดูหน้าเว็บ 3 วินาทีแรกต้องรู้ว่า "เว็บนี้คืออะไร ให้กดตรงไหน". จัดลำดับ:

  1. พาดหัวใหญ่บอกว่าเว็บนี้ทำอะไร (ไม่ใช่ชื่อทีม)
  2. ประโยคเดียวขยายความ สีจางกว่า
  3. ปุ่มหลัก 1 ปุ่ม สีแบรนด์เด่น
  4. ที่เหลือค่อยไล่ลงไป

6. แบบฝึกหัด (ทำเลย 15 นาที)

โจทย์: เปิด templates/landing.html ใน VS Code. อย่าเพิ่งอ่านโค้ดหมด.
1) เปิดในเบราว์เซอร์ ดูหน้าตาก่อน
2) กลับมาที่โค้ด หา <header> <section> <footer> — จับคู่กับสิ่งที่เห็นบนจอ
3) เปลี่ยนข้อความใน h1 แล้ว save ดูผล
4) เปลี่ยนค่า --brand ใน :root เป็น #ff6b35 — สังเกตว่าทั้งเว็บเปลี่ยนสีพร้อมกัน
เข้าใจข้อ 4 = คุณเข้าใจ design system แล้ว.
