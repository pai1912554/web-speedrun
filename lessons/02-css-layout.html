LESSON 02

CSS: 20% ที่ครอบ 80% ของงาน

CSS มี property เป็นพันตัว. ตอนแข่งคุณใช้จริงประมาณ 25 ตัว. นี่คือ 25 ตัวนั้น.

1. เขียน CSS ยังไงไม่ให้มั่ว — เขียนตามลำดับนี้เสมอ

1) tokens   :root{ --สี --ระยะ }
2) reset    *{box-sizing:border-box} *{margin:0}
3) base     body, a, h1..h6
4) layout   .wrap .grid .flex-row
5) component .card .btn .nav .form
6) responsive @media

เขียนสลับลำดับ = ทับกันเอง = เสียเวลาไล่หา. ท่องลำดับนี้.

2. Reset 5 บรรทัด (พิมพ์ก่อนเสมอ)

*,*::before,*::after{ box-sizing: border-box; }
*{ margin: 0; }
body{ min-height: 100vh; line-height: 1.6; }
img,svg,video{ display: block; max-width: 100%; }
input,button,select,textarea{ font: inherit; }
box-sizing:border-box คืออะไร: ปกติกำหนด width:200px แล้วใส่ padding 20px กล่องจะกลายเป็น 240px (บวกเพิ่ม!). ใส่บรรทัดนี้ปุ๊บ กล่องเป็น 200px เป๊ะตามที่สั่ง padding อยู่ข้างใน. นี่คือสาเหตุอันดับ 1 ที่ layout มือใหม่พัง.

3. ตัวแปร CSS = อาวุธลับความเร็ว

:root{
  --brand:#4f8cff;  --bg:#0f1115;  --text:#e8eaed;  --muted:#9aa4b2;
  --line:#2a2f3a;   --r:12px;      --sp:16px;
}
.btn{ background: var(--brand); border-radius: var(--r); }
.card{ border: 1px solid var(--line); padding: var(--sp); }

อยากเปลี่ยนธีมทั้งเว็บ? แก้ที่ :root บรรทัดเดียว. ตอนแข่งกรรมการบอก "อยากได้โทนเขียว" คุณแก้ 3 วินาที ทีมอื่นไล่แก้ 40 จุด.

4. Flexbox — ใช้กับ "ของเรียงแถวเดียว"

.row{ display:flex; align-items:center; gap:16px; }
เขียนได้อะไร
display:flexลูกๆ เรียงเป็นแถวนอน
gap:16pxระยะห่างระหว่างลูก (ใช้อันนี้ อย่าใช้ margin)
align-items:centerจัดกลางแนวตั้ง — โลโก้กับเมนูตรงกันพอดี
justify-content:space-betweenดันซ้ายสุด-ขวาสุด (header คลาสสิก)
margin-left:autoดันตัวนี้ไปขวาสุดตัวเดียว
flex-wrap:wrapล้นแล้วขึ้นบรรทัดใหม่ (กันพังบนมือถือ)
flex:1ตัวนี้ยืดกินที่ว่างที่เหลือ
flex-direction:columnเรียงลงแนวตั้งแทน
สูตรจัดกลางกลางจอ: 
display:flex; align-items:center; justify-content:center; min-height:100vh;
ใช้ทำหน้า login ได้เลย.

5. Grid — ใช้กับ "ตารางของหลายแถว"

สูตรเดียวที่ต้องจำ (การ์ดสินค้า, แกลเลอรี, dashboard):

.grid{
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(240px, 1fr));
  gap: 16px;
}

แปลว่า: "ยัดการ์ดให้ได้มากที่สุด แต่ละใบห้ามแคบกว่า 240px ที่เหลือแบ่งเท่าๆ กัน". อันนี้ responsive อัตโนมัติ ไม่ต้องเขียน media query เลย. จอใหญ่ได้ 4 คอลัมน์ มือถือเหลือ 1 เอง.

Layout dashboard (sidebar + เนื้อหา):

.app{ display:grid; grid-template-columns: 240px 1fr; min-height:100vh; }

6. ทำให้ดู "แพง" ใน 6 บรรทัด

.card{
  background:#171a21;
  border:1px solid #2a2f3a;      /* เส้นขอบบางๆ = คมขึ้นเยอะ */
  border-radius:12px;             /* มุมมน */
  padding:24px;                   /* ที่หายใจ */
  box-shadow:0 6px 24px rgba(0,0,0,.35);
  transition:.18s;                /* ทุกอย่างนุ่มขึ้น */
}
.card:hover{ transform:translateY(-2px); border-color:var(--brand); }
3 อย่างที่ทำให้งานมือใหม่ดูโปรทันที: border-radius + transition + gap ที่สม่ำเสมอ. ใส่ทุกที่.

7. Responsive แบบขี้เกียจแต่ได้ผล

ลำดับความสำคัญ — ทำ 3 อย่างนี้ก่อน แล้วเว็บจะรอดมือถือ 90%:

/* 1. wrapper กันชนขอบ */
.wrap{ width: min(1080px, 100% - 32px); margin-inline: auto; }

/* 2. ตัวหนังสือย่อ-ขยายเอง */
h1{ font-size: clamp(28px, 5vw, 46px); }
/*        เล็กสุด, ยืดหยุ่น, ใหญ่สุด */

/* 3. grid auto-fit (ข้อ 5) */

ถ้ายังต้องแก้เพิ่ม ใช้ media query จุดเดียวพอ:

@media (max-width: 768px){
  .app{ grid-template-columns: 1fr; }   /* sidebar หล่นลงล่าง */
  nav.top{ display:none; }
}

8. position — รู้ 3 อย่างพอ

ค่าใช้เมื่อ
position:sticky; top:0;header ติดบนตอนเลื่อน (ต้องมี top ด้วยเสมอ)
position:fixed;Modal, ปุ่มลอย, toast — ลอยเหนือทุกอย่าง
position:relative; ที่พ่อ + absolute ที่ลูกวางป้าย "ลด 50%" มุมรูป
.badge-wrap{ position:relative; }
.badge{ position:absolute; top:8px; right:8px; }

9. ตารางแก้ปัญหาที่เจอบ่อยที่สุด

อาการสาเหตุแก้
กล่องล้นออกนอกจอ / เลื่อนซ้ายขวาได้ลืม border-box หรือใช้ width:100% + paddingใส่ reset, ใช้ max-width:100%
จัดกลางไม่ได้ใช้ text-align กับกล่องflex + justify-content:center
รูปยืดผิดสัดส่วนกำหนดทั้ง w และ hobject-fit:cover
CSS ไม่ทำงานชื่อ class พิมพ์ผิด / เขียนทับกันF12 ดู Elements ว่า class ติดไหม
ของทับกันมั่วz-indexให้ header z-index:50, modal z-index:100
เมนูมือถือพังไม่มี flex-wrapใส่ flex-wrap:wrap
