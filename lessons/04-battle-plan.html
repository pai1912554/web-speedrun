LESSON 04

แผนรบ 3 ชั่วโมง — นาทีต่อนาที

พิมพ์หน้านี้ออกมา หรือเปิดคาไว้อีกจอ. ดูนาฬิกาทุก 15 นาที.

ตารางเวลา

เวลาทำอะไรเสร็จแล้วต้องได้
0–10
วางแผน		 อ่านโจทย์ 2 รอบ. เขียนใส่กระดาษ: หน้ากี่หน้า, ฟีเจอร์อะไรบ้าง, อะไรคือ "ของที่กรรมการจะกด". วงกลม ฟีเจอร์เดียว ที่เป็นหัวใจ. เลือกเทมเพลตจากคลัง. รายการฟีเจอร์เรียงลำดับความสำคัญ 1-2-3
10–25
โครง		 copy เทมเพลตมาตั้งชื่อ index.html. แก้ tokens ใน :root (สีตามธีมโจทย์), แก้ชื่อเว็บ/โลโก้/เมนู. เปิด Live Server. เว็บเปิดได้ มีสีธีมของงาน มี header/footer
25–55
หน้าตา		 ใส่เนื้อหาจริงลง Hero + section หลัก. ยังไม่ต้องเขียน JS. ข้อความจริง รูปจริง (ใช้ picsum.photos ถ้าไม่มีรูป). หน้าเว็บดูเสร็จแล้ว 1 หน้า ถ้าหมดเวลาตรงนี้ก็ยังส่งได้
55–70
เซฟตัว		 หยุด. บันทึกสำเนา backup-1.html. นี่คือจุดปลอดภัย. มีของที่ส่งได้แน่ๆ อยู่ในมือ
70–130
ฟีเจอร์หลัก		 เขียน JS ฟีเจอร์ที่วงกลมไว้ ให้สมบูรณ์อันเดียว: data + render + event. ทดสอบทุก 10 นาที. ฟีเจอร์หัวใจกดแล้วทำงานจริง ไม่มี error แดงใน Console
130–150
เพิ่มแต้ม		 เลือก 2 อย่างจาก: localStorage (ข้อมูลไม่หาย) · ช่องค้นหา · dark mode toggle · ตัวนับ/สรุปยอด · animation ตอน scroll. เลือกที่ทำเสร็จใน 10 นาทีเท่านั้น. ดูมีของมากกว่าที่โจทย์ขอ
150–165
มือถือ		 F12 กด Ctrl+Shift+M ดูมือถือ. แก้เฉพาะที่ล้น/ทับ. อย่าเพิ่งจัดสวย เอาแค่ไม่พัง. มือถือไม่มีของล้นออกนอกจอ
165–180
ส่ง		 Checklist ข้างล่าง. ห้ามเขียนโค้ดใหม่ในช่วงนี้เด็ดขาด. ส่งทัน
กฎเหล็ก: นาทีที่ 150 หยุดเพิ่มฟีเจอร์ทุกกรณี. คนแพ้ส่วนใหญ่ไม่ได้แพ้เพราะทำน้อย แต่แพ้เพราะเพิ่มของนาทีที่ 170 แล้วพังยกเว็บ.

Checklist 15 นาทีสุดท้าย

  1. เปิดเว็บใหม่หมดจาก URL — โหลดขึ้นไหม
  2. F12 Console — มีตัวแดงไหม (มี = แก้ หรือคอมเมนต์ทิ้ง)
  3. กดทุกปุ่มทีละปุ่ม — ไม่มีปุ่มไหนกดแล้วเงียบ
  4. ลิงก์เมนูทุกอันไปถึงที่
  5. รูปขึ้นครบ ไม่มีไอคอนรูปแตก
  6. มือถือ (Ctrl+Shift+M) ไม่ล้น
  7. ไม่มีคำว่า "Lorem ipsum" / "ชื่อเว็บ" / "test" หลงเหลือ
  8. <title> เป็นชื่องานจริง
  9. ทุก img มี alt
  10. ตั้งชื่อไฟล์ให้ถูกตามที่โจทย์กำหนด แล้วส่ง

ลำดับความสำคัญตอนเวลาไม่พอ (ตัดอะไรก่อน)

ตัดได้ทันทีห้ามตัด
Animation, ธีมมืด, หน้ารอง, ฟอร์มติดต่อที่ส่งจริง, API จริง หน้าแรกดูดี, ฟีเจอร์หัวใจทำงาน, ไม่มี error, มือถือไม่พัง

คำถามที่ต้องถามตัวเองตอนได้โจทย์

  1. กรรมการจะกดอะไร? สิ่งนั้นต้องทำงาน 100%
  2. ข้อมูลของโจทย์คืออะไร? สินค้า? นักเรียน? อีเวนต์? เขียนเป็น array of object ทันที
  3. ต้องมีกี่หน้าจริงๆ? ส่วนใหญ่หน้าเดียวเลื่อนลงพอ (one-page) แล้วดูดีกว่าหลายหน้าที่ทำไม่เสร็จ
  4. เทมเพลตไหนใกล้ที่สุด? เปิดจากคลัง อย่าเริ่มจากไฟล์เปล่า

  • นอน. สมองล้า = พิมพ์ผิดเยอะ = เสียเวลา debug มากกว่าที่อ่านเพิ่มได้
