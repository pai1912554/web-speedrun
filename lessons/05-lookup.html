LESSON 05

ได้โจทย์มาแล้ว — ค้นอะไร ที่ไหน

2. ค้นที่ไหน (เรียงตามความคุ้ม)

ที่ใช้ตอนวิธีค้น
คลังของเว็บนี้ก่อนอื่นเสมอเปิด templates/ + snippets/ ดูก่อน 30 วินาที
MDN (developer.mozilla.org)ไม่แน่ใจว่า property/method ใช้ยังไงGoogle: mdn flexbox · mdn array filter
CSS-Tricksอยากได้ตัวอย่าง layout ครบๆcss tricks flexbox guide
Stack Overflowเจอ error แปลกๆcopy บรรทัด error ไปวางใน Google ทั้งบรรทัด
CodePenอยากเห็นเอฟเฟกต์แล้วขโมยโค้ดcodepen pricing card
DevTools (F12)ทุกครั้งที่หน้าตาไม่ตรงใจคลิกขวาที่ของนั้น > Inspect แล้วแก้ CSS สดๆ ก่อน copy กลับ
เทคนิคค้นให้เจอเร็ว: ใช้ภาษาอังกฤษ + คำว่า css หรือ javascript นำหน้า เช่น css center div vertically, javascript filter array by input. อย่าค้นภาษาไทย ผลลัพธ์แย่กว่ามาก.

3. เจอ error ทำยังไง (30 วินาทีรู้เรื่อง)

ข้อความ errorแปลว่าแก้
Cannot read properties of nullquerySelector หาไม่เจอ ได้ null มาเช็คว่าพิมพ์ชื่อ id/class ถูกไหม และ <script> อยู่ล่างสุดของ body
X is not definedตัวแปร/ฟังก์ชันสะกดผิด หรือยังไม่ประกาศเช็คตัวพิมพ์เล็กใหญ่
X is not a functionเรียกเมธอดผิดชนิด เช่น .map() บน objectconsole.log(x) ดูว่ามันคืออะไร
Unexpected tokenวงเล็บ/ปีกกาไม่ครบดูบรรทัดที่บอก แล้วไล่ขึ้นไป 2-3 บรรทัด
CORS policy / fetch พังเปิดไฟล์แบบ file:// หรือ API ไม่อนุญาตใช้ Live Server; ถ้ายังพัง เปลี่ยนไปใช้ข้อมูลปลอม
ไม่มี error แต่หน้าเปล่าrender ไม่ถูกเรียกใส่ console.log('render', data) ในฟังก์ชัน
วิธี debug ที่เร็วที่สุดในโลก: console.log() ใส่ไปเลย 5 จุด ดูว่ามันวิ่งถึงจุดไหน แล้วค่าเป็นอะไร. อย่านั่งจ้องโค้ดเดา.

4. เช็กลิสต์ "ได้คะแนนฟรี" ที่คนอื่นมักลืม

  • <html lang="th">
  • <title> ตรงกับงาน + <meta name="description">
  • ทุกรูปมี alt ที่สื่อความหมาย
  • ทุก input มี <label for="id"> คู่กับ id
  • ใช้ header main section footer nav แทน div ล้วน
  • ปุ่มใช้ <button> ลิงก์ใช้ <a> (กด Tab เลื่อนได้ = accessibility)
  • ตัวหนังสือกับพื้นหลังคอนทราสต์พอ (อย่าเทาอ่อนบนขาว)
  • โค้ดจัดย่อหน้าสวย (VS Code: Shift+Alt+F)
  • ใส่คอมเมนต์หัวข้อในไฟล์ /* ===== HEADER ===== */ กรรมการอ่านโค้ดแล้วชอบ

5. ประโยคที่ควรพูดตอนนำเสนอ

  1. "เว็บนี้แก้ปัญหา___ ให้กลุ่ม___" (ไม่ใช่ "ผมทำหน้าแรก หน้าสอง...")
  2. สาธิตของจริง: กดปุ่ม เพิ่มข้อมูล ค้นหา ให้เห็นว่าทำงาน
  3. "ผมใช้ตัวแปร CSS ทำ design system เปลี่ยนธีมทั้งเว็บได้จากจุดเดียว" (โชว์เลย)
  4. "ข้อมูลเก็บใน localStorage รีเฟรชแล้วไม่หาย" (รีเฟรชให้ดู)
  5. "responsive ครับ" แล้วย่อหน้าต่างให้ดู
