LESSON 06

ตั้ง VS Code ให้เร็วขึ้น 2 เท่า

นี่คือช่องว่างที่แท้จริงระหว่างคุณกับคนมีประสบการณ์. เขาพิมพ์ 3 ตัวได้ 10 บรรทัด. เรียนรู้ได้ใน 15 นาที.

1. ส่วนขยายที่ต้องมี (ติดตั้งคืนนี้เลย)

ชื่อทำอะไรจำเป็น
Live Server (Ritwick Dey)คลิกขวา > Open with Live Server = เว็บรีเฟรชเองทุกครั้งที่ saveต้องมี
Auto Rename Tagแก้ <div> เป็น <section> ปิดท้ายเปลี่ยนตามต้องมี
Prettierจัดโค้ดสวยอัตโนมัติควรมี
Error Lensโชว์ error ท้ายบรรทัดเลย ไม่ต้องเลื่อนหาควรมี
Thai Language Packเมนูภาษาไทยตามชอบ

ติดตั้ง: กด Ctrl+Shift+X พิมพ์ชื่อ กด Install.

2. Emmet — อาวุธหลัก (มีมาให้ในตัวแล้ว)

พิมพ์ย่อ แล้วกด Tab. ได้ HTML เต็มทันที.

พิมพ์กด Tab แล้วได้
!โครง HTML ทั้งหน้า (doctype, head, meta viewport ครบ)
div.card<div class="card"></div>
div#app<div id="app"></div>
ul>li*5ul พร้อม li 5 อัน
ul>li*3>a{เมนู $}li 3 อัน แต่ละอันมีลิงก์ "เมนู 1/2/3"
section.hero>h1+p+a.btnsection ที่มี h1, p, ปุ่ม เรียงกัน
.card*6div.card 6 ใบ (ละ div ได้เลย)
header>.wrap>.logo+nav>a*4header ทั้งชุดในบรรทัดเดียว
lorem20ข้อความหลอก 20 คำ
table>tr*3>td*4ตาราง 3x4
จำ 4 สัญลักษณ์นี้พอ: .=class · #=id · >=ลูก · +=พี่น้อง · *=ทำซ้ำ · {}=ข้อความ

3. คีย์ลัดที่ประหยัดเวลาที่สุด

ปุ่มทำอะไรใช้ตอน
Alt+Shift+↓ก๊อปบรรทัดลงล่างทำการ์ดใบที่ 2-3-4
Alt+↑/↓ย้ายบรรทัดขึ้นลงสลับลำดับ section
Ctrl+Dเลือกคำเดียวกันตัวถัดไป (กดซ้ำได้)เปลี่ยนชื่อ class ทุกที่พร้อมกัน
Alt+คลิกวางเคอร์เซอร์หลายจุดพิมพ์พร้อมกันหลายบรรทัด
Ctrl+/คอมเมนต์/ยกเลิกปิดโค้ดที่พังชั่วคราวก่อนส่ง
Shift+Alt+Fจัดย่อหน้าโค้ดสวยก่อนส่งงาน ทำทุกครั้ง
Ctrl+Pเปิดไฟล์ด้วยการพิมพ์ชื่อสลับไฟล์เร็ว
Ctrl+F / Ctrl+Hหา / หาและแทนที่เปลี่ยนชื่อทั้งไฟล์
Ctrl+Bซ่อนแถบข้างจอเล็ก
Ctrl+\แบ่งจอ 2 ฝั่งดู HTML กับ CSS พร้อมกัน
Ctrl+Spaceเรียก autocompleteลืมชื่อ property

4. Snippet ของตัวเอง (ทำครั้งเดียว ใช้ตลอด)

ให้พิมพ์ !! แล้วได้โครงเว็บพร้อม design tokens ทันที:

  1. กด Ctrl+Shift+P พิมพ์ Configure User Snippets
  2. เลือก html.json
  3. วางโค้ดข้างล่าง แล้ว save
{
  "Speedrun base": {
    "prefix": "!!",
    "body": [
      "<!doctype html>",
      "<html lang=\"th\"><head><meta charset=\"utf-8\">",
      "<meta name=\"viewport\" content=\"width=device-width,initial-scale=1\">",
      "<title>$1</title>",
      "<style>",
      ":root{--bg:#0f1115;--surface:#171a21;--text:#e8eaed;--muted:#9aa4b2;",
      "--line:#2a2f3a;--brand:#4f8cff;--r:12px;}",
      "*,*::before,*::after{box-sizing:border-box}*{margin:0}",
      "img{display:block;max-width:100%}input,button{font:inherit}",
      "body{background:var(--bg);color:var(--text);line-height:1.7;",
      "font-family:system-ui,'Noto Sans Thai',sans-serif}",
      ".wrap{width:min(1080px,100% - 32px);margin-inline:auto}",
      ".grid{display:grid;gap:16px;grid-template-columns:repeat(auto-fit,minmax(240px,1fr))}",
      ".card{background:var(--surface);border:1px solid var(--line);",
      "border-radius:var(--r);padding:24px;transition:.18s}",
      ".btn{background:var(--brand);color:#fff;border:0;padding:10px 18px;",

    ]
  }
}
ผลลัพธ์: นาทีที่ 0 ของการแข่ง คุณพิมพ์ !! Tab แล้วมี design system พร้อมทันที. คนอื่นยังพิมพ์ <!doctype> อยู่.

5. DevTools (F12) — 3 แท็บที่ต้องใช้

แท็บใช้ทำอะไร
Consoleดู error แดง + ทดลองรันโค้ด JS สดๆ
Elementsคลิกขวาที่ของบนเว็บ > Inspect. แก้ CSS สดๆ ทางขวา เห็นผลทันที แล้วค่อย copy กลับไปใส่ไฟล์ เร็วกว่าแก้ในโค้ดแล้วเซฟดูเยอะ
Application > Local Storageดูว่าข้อมูลที่เซฟไปหน้าตาเป็นยังไง / กดลบตอนเทสต์

Ctrl+Shift+M = สลับโหมดมือถือ. เช็คทุกครั้งก่อนส่ง.
