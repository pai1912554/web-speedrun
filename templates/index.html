เทมเพลต 8 แบบ — ไฟล์เดียวจบทุกอัน

ทุกไฟล์เป็น HTML+CSS+JS ในไฟล์เดียว ไม่ต้องติดตั้งอะไร copy ไปวางแล้วแก้ได้ทันที. ทุกไฟล์ใช้ชุดตัวแปรสีเดียวกัน จำครั้งเดียวใช้ได้หมด.

วิธีใช้ตอนแข่ง: เปิดไฟล์ที่ใกล้โจทย์ที่สุด > Ctrl+A Ctrl+C > วางในไฟล์ใหม่ > แก้ :root (สี) > แก้ข้อความ > แก้ array ข้อมูล. 15 นาทีได้เว็บที่ดูโปร.

เลือกตามโจทย์

01 · LANDING

หน้าแนะนำ / One-page

Hero + ฟีเจอร์ + ราคา + ติดต่อ + เมนูเลื่อนนุ่ม. ใช้ได้กับ 50% ของโจทย์ ถ้าไม่รู้จะเลือกอะไร เอาอันนี้.
02 · DASHBOARD

แดชบอร์ด + กราฟ

Sidebar + การ์ดตัวเลขสถิติ + กราฟแท่งทำจาก CSS ล้วน + ตารางล่าสุด. โจทย์ "ระบบจัดการ" ใช้อันนี้.
03 · CRUD

ตาราง เพิ่ม/ลบ/แก้/ค้นหา

ครบทุกท่า JS + localStorage + เรียง + กรองหมวด + สรุปยอด. เทมเพลตที่ได้คะแนนง่ายที่สุด.
04 · FORM

ฟอร์มลงทะเบียน + ตรวจข้อมูล

input ทุกชนิด, validation แบบแสดงข้อความใต้ช่อง, สรุปผลหลังส่ง.
05 · LOGIN

เข้าสู่ระบบ / สมัคร

จัดกลางจอ + สลับแท็บล็อกอิน/สมัคร + ซ่อน-แสดงรหัส + จำผู้ใช้ใน localStorage.
06 · GALLERY

แกลเลอรี / สินค้า + ตะกร้า

Grid การ์ดสินค้า + กรองหมวด + ค้นหา + ตะกร้าคิดเงินรวม + Modal ดูรูปใหญ่.
07 · BLOG

บทความ / ข่าวสาร

รายการบทความ + อ่านต่อในหน้าเดียว + แท็กหมวด + เวลาอ่าน.
08 · PORTFOLIO

แนะนำตัว / ผลงาน

ประวัติ + ทักษะแบบแถบเปอร์เซ็นต์ + ผลงาน + ไทม์ไลน์ + ติดต่อ. โจทย์ "แนะนำตัวเอง/ทีม" ใช้อันนี้.

สิ่งที่ควรทำก่อนวันแข่ง

  1. เปิดทุกไฟล์ในเบราว์เซอร์ดู 1 รอบ (5 นาที) ให้จำหน้าตาได้
  2. เลือกมา 2 อัน แล้วลองแก้เป็นธีมอื่น เช่น landing เป็นเว็บร้านกาแฟ
  3. สังเกตว่าทุกไฟล์มีโครงเหมือนกันเป๊ะ: tokens > reset > layout > component > DATA > render > events
